This project is for a warehouse or supply chain manager who needs to keep stock available and orders moving across connected systems such as WCS, TMS, and ERP. Their daily problems are stock-outs, late shipments, and interface errors between these systems that are slow to diagnose. The tool is a small control tower that forecasts demand, analyses interface errors with AI, answers SOP questions through a RAG chatbot, and shows warehouse health on a dashboard covering available inventory, pending orders, and interface errors. A simple AI agent acts on what it finds: it drafts a reorder suggestion when forecast demand exceeds stock, and raises a ticket when the same interface error occurs twice within an hour. It runs entirely on synthetic data as a proof of concept, and it succeeds if forecasts are accurate enough to trigger sensible reorder suggestions, error causes are explained clearly, SOP answers trace back to the source document, and the dashboard reflects the current state of the warehouse.
